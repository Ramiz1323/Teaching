# Not the Basics - Backend Engineering & Web Development Teaching Series

Welcome to the comprehensive teaching repository for mastering Backend Web Development with Node.js, Express, and MongoDB.

## 📚 Curriculum Structure

| Module | Topic | Key Concepts |
|---|---|---|
| **[Day01 - Git](./Day01%20-%20Git/)** | Git & Express Init | Version control fundamentals, Express server bootstrap |
| **[Day02 - Backend Basics](./Day02%20-%20Backend%20Basics/)** | HTTP Routing | Request/Response cycle, status codes, route handlers |
| **[Day03 - Intro to Postman](./Day03%20-%20Intro%20to%20Postman/)** | API Testing | Postman testing, JSON body parser, input validation |
| **[Day04 -](./Day04%20-/)** | REST Architecture | Separation of Concerns (app.js vs server.js), CRUD endpoints |
| **[Day05 - MongoDB](./Day05%20-%20MongoDB/)** | Database Connection | MongoDB connection lifecycle, Mongoose ODM |
| **[Day06 - Response](./Day06%20-%20Response/)** | Response Standards | Express Router, response standardization, request logger |
| **[Day07 - Models](./Day07%20-%20Models/)** | Mongoose Models | Schema design, validation, CRUD controllers, pre-save hooks |

## 🚀 Getting Started

1. Clone repository:
   ```bash
   git clone <repo-url>
   cd "Not the Basics"
   ```
2. Navigate to any day's directory:
   ```bash
   cd "Day07 - Models"
   npm install
   npm run dev # or node server.js
   ```
