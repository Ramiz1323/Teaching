# Day 02: Backend Basics

## Core Concepts Covered
1. **Express Server Lifecycle**:
   - Creating an instance using `express()`
   - Binding to a TCP port using `app.listen(PORT)`
2. **HTTP Request & Response**:
   - `req` (Request object): contains headers, parameters, query strings, and body.
   - `res` (Response object): provides methods like `res.send()`, `res.json()`, and `res.status()`.
3. **HTTP Status Codes**:
   - `200 OK`: Standard successful HTTP response.
   - `404 Not Found`: Resource could not be found.
