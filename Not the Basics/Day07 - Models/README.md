## Quick Start
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the application:

## Endpoints
| Method | Route | Description | Expected Status |
|---|---|---|---|
| `POST` | `/notes` | Creates a new note in MongoDB | `201 Created` |
| `GET` | `/notes` | Fetches all notes from MongoDB | `200 OK` |
