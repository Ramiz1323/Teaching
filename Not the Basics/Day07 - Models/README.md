# Day 07: MongoDB Models & Schema Validation

## Features Implemented:
- **Mongoose Model**: `Note` schema with strict validation, default fields, and automated timestamps.
- **Controller-Router Architecture**: Clear division between route endpoints and controller business logic.
- **Full CRUD Endpoints**:
  - `POST /api/notes` - Create a note
  - `GET /api/notes` - Fetch all notes
  - `GET /api/notes/:id` - Fetch single note
  - `PATCH /api/notes/:id` - Update note
  - `DELETE /api/notes/:id` - Remove note
