## Types of Routers:-
1. [ ] Browser Router :-
    - History API
    - URL looks clean
    - Modern Apps
    - SEO Friendly
    - Needs server configuration

2. [ ] Hash Router :-
    - Hash in URL (/#/home)
    - No server configuration needed
    - Not SEO Friendly
    - Not Modern Apps

3. [ ] Memory Router :-
    - Keeps history in memory
    - Used for testing or non-browser environments
    - Not SEO Friendly
    - Not Modern Apps

4. [ ] Static Router :-
    - Used for server-side rendering(SSR)
    - No client-side navigation
    - Not SEO Friendly
    - Not Modern Apps
